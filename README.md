## Modifications and Contributions

This fork introduces several adaptations and extensions:

- Replaced the original Xiaohei character system with an orange-haired pixel-art character known as "橘子头".
- Developed a distinct pixel-art visual language, character guidelines, and composition rules.
- Extended the workflow to support article covers, body illustrations, and summary infographics.
- Added dedicated WeChat article cover generation workflows.
- Introduced a Python tool for image dimension validation and cover composition.
- Expanded prompt templates, documentation, and quality assurance guidelines.

These modifications aim to make AI-assisted visual content creation more accessible, consistent, and reusable for Chinese-speaking creators.
